Notchly
Widgets Build one Star

A panel for the edge of your screen.

Notchly sits against the bezel. Closed, it shows what you want to keep an eye on. Reach for it and it opens into your widgets — the five it ships with, or the ones you write yourself.

Download macOS and Windows · free · MIT

Closed, it still answers things.

The handle holds readings you pick — the time, load, memory, battery, what's playing. Anything that's a fraction of something draws an arc, so you can read it without stopping to read it. Rest on one and its detail appears without opening the panel.

Open, it's whatever you put in it.

  • Clock time, date, week number
  • Now Playing controls for Music and Spotify
  • System CPU, memory, disk, network, battery
  • Launcher search and open any app
  • Clipboard searchable history of what you copied

Your widget is a folder.

No SDK, no build step, no signing. Drop a folder in and Notchly picks it up immediately; save a file and it reloads while you watch. It's HTML in a webview — the same kind of thing the panel itself is.

Widgets are sandboxed with an opaque origin. Network, shell and clipboard access are refused until you grant them, and a widget's token is kept in the OS keychain rather than a settings file. 

my-widget/
  widget.json
  index.html

// widget.json
{
  "id": "com.you.my-widget",
  "name": "My Widget",
  "permissions": ["network"]
}

// index.html
const stats = await notchly.system.stats()
const city  = await notchly.settings.get('city')

It doesn't phone home.

No analytics, no accounts, no network requests of its own. Clipboard history stays on your machine. The whole thing is a Rust binary and a folder of HTML you can read.
